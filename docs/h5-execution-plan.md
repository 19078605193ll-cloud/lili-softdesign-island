# 软设岛 H5 用户端执行记录

修订日期：2026-09-29。本轮确认方案已实施，当前已完成本机业务部署，数据库版本0014。

## 已确认范围

- 五张设计图以 `sucai/` 为依据；保持布局、背景色和配色，图标与机器人允许近似。缺稿页面沿用现有风格扩展。
- Vue 3、TypeScript、Vite、Vue Router、Pinia；npm锁文件；原生CSS与自建组件；fetch同源Cookie/CSRF。工程位于 `web/h5/`，入口 `/h5/`。
- 首页、真题/章节、答题、错题本、登录形成学习闭环。没有独立“我的”页，账号与退出放在首页弹层。
- 错题卡片显示两行题干摘要；手动解除只影响当前Tab。仅从错题/犹豫Tab重练整题全对时双解除，收藏不变；普通练习答对不解除，再次答错可重新入本。
- 共享Markdown、HTML表格、公式渲染，区分公开题图、本人历史题图和后台素材权限。历史结果从作答快照读取。
- AI使用后端OpenAI兼容接口及两份提示词，必要时直接讲解；首版支持结构图和步骤图。
- 教学变式题独立存库，结构及答案复核通过后跨用户共享；会话引用题目ID，不共享私人对话。教学作答不计正式成绩、掌握度或错题本。

## 实施与部署

1. 固定图片及提示词依据，登记哈希及设计差异，补齐接口与统计约定。
2. 建立H5、认证、组件和安全富文本渲染，新增兼容迁移0014。
3. 实现真实API、会话草稿、幂等提交、错题状态、统计与返回恢复。
4. 复用持久任务/outbox实现AI、限流、轮询、历史、教学题生成/复核/复用/反馈。
5. 完成隔离回归、前端构建、Chromium/WebKit验证；备份业务数据库及素材，在独立副本验证恢复升级后迁移业务环境，重新创建API/worker/dispatcher。
