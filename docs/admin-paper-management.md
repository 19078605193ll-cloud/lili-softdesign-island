# 管理员试卷删除、恢复与标题编辑

管理员“导入批次”列表现在提供“编辑标题”和“删除”。已发布试卷删除后进入“已删除”列表，可恢复；未发布批次仍为永久删除，不进入回收站。

## 已发布试卷

- 删除整套正式试卷，同时隐藏所有关联已发布批次。确认框显示关联批次数。
- 删除使用现有 `exam_papers.status=retired`，恢复为 `verified`；不删除题目、源文件、题图、作答快照或AI对话，不需要数据库迁移。
- 用户题库、章节练习及类似题检索排除已删除试卷；旧页面的新作答、类似题和AI提问请求由服务端阻止。
- 最近学习记录和错题本仍保留本人历史答案入口。已删除题目的AI面板只展示已有对话。
- 恢复后重新可练，原进度与答案保留。发布或补充导入不能自动恢复已删除试卷。
- 关联批次存在排队、运行或等待重试任务时拒绝删除；失败任务须在试卷恢复后才能重新发起。

## 标题

标题去除首尾空白，长度为1—300字。未发布批次只修改自身；已发布批次同步正式试卷及全部关联已发布批次。用户端题库、普通试卷答题标题及最近学习记录读取最新正式标题，原作答快照保持原样。

年份、场次与批次编码不通过标题编辑接口修改。错题重练等上下文标题继续显示“错题重练”等名称。

## 接口

| 接口 | 行为 |
| --- | --- |
| `GET /admin/imports?view=active` | 默认正常列表 |
| `GET /admin/imports?view=deleted` | 已删除试卷的关联批次列表，过滤先于数量限制 |
| `PATCH /api/v1/admin/import-batches/{id}/title` | JSON `{ "title": "新标题" }`，返回批次详情 |
| `DELETE /api/v1/admin/import-batches/{id}` | 已发布返回 `soft_deleted=true`；未发布沿用原清理流程 |
| `POST /api/v1/admin/import-batches/{id}/restore` | 恢复关联整套试卷 |

写操作沿用CSRF、管理员权限与 `If-Match` 批次版本检查。删除/恢复需 `imports:delete`，标题编辑需 `imports:edit`；旧版本返回409，缺少版本返回428。重复删除/恢复使用当前版本时幂等，旧页面不得覆盖较新的修改。
审计记录操作、关联对象以及标题前后值。发布、删除、恢复、改名和相关任务创建按同一试卷标识串行化，防止并发发布覆盖删除状态。
