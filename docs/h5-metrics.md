# H5 统计规则 h5-v1

- 真题总量：当前科目通过既有发布可见性检查的整题数。完成量是该集合与本人历史作答整题集合的交集；多次重练不累计，分子不会超过分母。
- 综合正确率：本人该科目正式作答累计正确小问数 / 累计作答小问数，含重复练习。无作答为null，不显示伪造的0%或示例成绩。
- 当前知识样本：只使用当前题目版本的小问最近一次作答；主知识点和知识体系release必须与作答知识快照一致。
- 掌握：某个有可练题的叶子知识点练过至少3道不同小问，最近结果正确率≥80%，且该知识点没有活跃错题/犹豫题。
- 首页掌握度：已掌握叶子数 / 有可练题叶子数。没有可练题时为null；有题但没掌握时为0%。
- 章节进度：本章及后代采用相同叶子集合和规则。无作答=未练习；没有任何达到最低样本数的知识点=样本不足；之后按进度≥70%、≥40%、<40%分别显示基本掌握、正在提升、需要加强。
- 章节历史分值：仅使用已发布可练小问分值总和等于试卷声明总分、且总分非零的完整样本。按已确认主知识点归属计算章节分值 / 样本总分，展示样本套数，不称为考试预测。无合格样本显示暂无统计。
- 最近记录：最近5次练习会话，显示整题完成量与小问正确率。只有旧作答没有会话时展示“历史练习”聚合，不伪造可恢复会话。
- 考期使用Asia/Shanghai自然日。起始日不得晚于考试日；同日周期在到达考试日后为100%；其他进度截断到0–100%。
- 教学变式题的回答与反馈不进入以上任何正式学习统计。

2026-09-30：题库列表的“已答n/总数”仍按不同正式整题统计；“上次停在第n题”使用续练会话位置，二者不等同。paper/node继续练习不会新增一轮或重复提交已有答案；类似题命中真题时沿用正式统计，教学池命中及生成题不计正式成绩。

作答提交与错题状态在单一事务内生效。前端根据服务端结果展示；科目切换后重新请求，不混用旧科目数据。无算法支持的专注度百分比、考频星级不显示。
