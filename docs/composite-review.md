# 组合题审核与修复

安装更新依赖后执行 `python -m alembic upgrade head`，新增两张题组表的可空公共解析字段。迁移不修改已发布题目正文。

后台保留完整题干及每组独立选项。在题目审核页点击「查看规则修复建议」，展开修复前后字段对比，对照原文后保存采用。保存保留原始来源与历史快照，小问原题号不变时 ID 保持不变；内容变动的小问需重新确认知识点。已批准的题目不能生成修复建议。

新导入和保存后的合格草稿在配置 AI 后自动分类，每次请求最多五个小问，顺序完成。AI 调用期间当前请求等待；失败记录可以在小问区域查看并重试。没有配置 AI 时保留尚未分类状态。此版本没有独立后台任务队列。

`POST /api/v1/admin/markdown-batches/{id}/classify` 接受可选 `block_id`、`question_no`、`force`；指定小问必须同时指定题块。返回处理数量及 `results` 中每个已处理小问的状态和错误。并发分类返回 409；内容编辑使用批次事务锁与分类互斥。

`POST /api/v1/admin/markdown-batches/{id}/blocks/{block_id}/repair-preview` 返回 `before` 与 `suggestion`，不覆盖内容。采用仍使用原 PUT 题块接口。

正式题目读取接口增加 `parts[].locator`，包含原题号、显示标签及原文已有的明确空位标记；没有明确标记时 marker 为 null，不猜测普通括号的含义。答案接口增加顶层 `explanation_markdown`；公共解析不出现在题目读取响应中。

预览使用本地 MathML 渲染美元符号包围的 LaTeX，并对最终 HTML/MathML 统一过滤；不依赖外部公式 CDN。公式不支持时回退原文。知识点推荐理由、完整路径及失败原因在各小问审核区展示。


## 旧分类兼容

分类指纹区分 v1（题干、选项、答案、解析、公共材料）和 v2（另外包含原题号与公共解析）。所有候选读取、批准来源追踪和自动分类复用统一校验：优先匹配 v2；若 v1 匹配、公共解析为空、分类响应保留当前原题号，且所属小问、知识树版本及校验和一致，则直接复用历史候选。空指纹、无题号证据或内容不匹配的记录不能自动恢复。

兼容读取不改写历史指纹、不调用 AI，也不自动批准题目。服务重新加载代码后，所有已上传批次均适用；管理员无需逐套迁移或逐题重新匹配。内容确实变化的题目仍需重新分类。
