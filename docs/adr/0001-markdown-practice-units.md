# 0001 Markdown 草稿与刷题题目分离

状态：已采纳（2026-09-26）

## Context

扫描 PDF 的视觉提取不稳定，官方未开放完整真题；Markdown 整理版既有缺题，也有 2～5 个小问共享题干和图片。旧实现把每个原文题号作为一条正式题目，强制要求 75 题齐全。

## Decision

Markdown 先解析为可追溯的题块和审核草稿。只有内容、图片和每个小问的主知识点确认后才能发布。正式题库新增刷题题目父级，每个父级包含一个或多个独立判分的小问。题号缺失不阻止其他经审核的整题发布；歧义题块需核对或整题排除。相同试卷通过补充批次扩充，冲突由管理员整题处理并保存替换前版本。

## Consequences

历史正式题目在迁移时建立父级记录；历史导入和素材仍可查看。用户端按父级展示和提交，小问分别判分、分类。导入批次和已发布试卷的题数因此分别统计刷题题目数与小问数。


## 2026-09-26 补充：保持完整真题

组合题保留完整题干，仅依据原文明确编号定位各小问，不强制重写独立问题。已有小问题干继续兼容。无法明确拆分的解析归题组所有，读取题目不返回解析，答案接口单独返回公共解析与小问解析。

知识点由 AI 自动推荐预填，管理员批准整题时确认；分类绑定内容指纹和知识树版本。存量未发布草稿先展示修复建议及差异，采用后记录快照；已批准或已发布题目不自动重跑。
