# 用户名与头像

账号弹窗支持修改登录用户名和上传头像。用户名旁为无边框笔图标；头像为圆形，上传后可拖动、双指缩放或使用滑杆调整，再确认保存。保存提示1秒后消失。

## 数据与接口

- 迁移 `20260930_0016` 新增 `users.avatar_key`，旧用户为空；图片保存至持久化素材卷的 `avatars/{uuid}.webp`，数据库不保存图片二进制。
- `GET /api/v1/auth/me` 返回 `avatar_url`；`PATCH` 同路径仅接受 `username`，去除首尾空格并casefold，1—100字且无控制字符，重名返回409。用户ID、权限、密码及当前登录不变；以后用新用户名登录。
- `PUT /api/v1/auth/me/avatar` 接受multipart字段 `file,x,y,size`。坐标对应方向纠正后的图片像素，服务端校验并输出512×512 WebP；接受静态JPEG/PNG/WebP，最多5MB、2000万像素。
- `GET /api/v1/auth/me/avatar/{key}` 仅允许本人读取当前头像，旧版本及他人引用返回404；`DELETE /api/v1/auth/me/avatar` 恢复默认。
- 新文件保存后才更新数据库；更新失败清理新文件，成功后清理旧文件。清理失败记录日志，存储对账报告超过24小时的孤立头像文件。
- 现有整素材卷配套备份包含头像；`app.infrastructure.storage_audit` 同时检查头像引用缺失及孤立文件。
